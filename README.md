# South African War Virtual Tour (starter prototype)

## What is included
- `index.html`: the tour page
- `style.css`: page layout and styling
- `tour.js`: clickable locations, zoom behaviour, location stories and learner questions

## Important map note
The map is a schematic visual to demonstrate the interaction, not a geographically accurate map of historical borders. Before using this as a final history resource, replace it with a verified historical map or a properly georeferenced map. The included location list is a starter set, not an exhaustive catalogue of every battle or concentration camp.

## Publish with GitHub Pages
1. Sign in to GitHub and create a new public repository, for example `south-african-war-tour`.
2. Upload `index.html`, `style.css`, and `tour.js` to the repository's root.
3. Open the repository's **Settings** → **Pages**.
4. Under the build/deployment source, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. The Pages panel will show the public URL.
